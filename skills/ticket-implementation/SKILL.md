# Ticket Implementation

Purpose:

Implement only the requested ticket.

Rules:

- Read PRD.md and MVP-TICKETS.md before implementation.
- Build only the requested ticket.
- Do not build future tickets.
- Keep implementation minimal.
- Reuse existing patterns.
- Explain files created or modified.
- Explain what was deliberately not built.
- Run typecheck.
- Run build where relevant.
- Prefer maintainable code over clever code.
- Stop after ticket completion. Do not continue into adjacent tickets.

Workflow:

Read ticket

↓

Plan minimal implementation

↓

Implement

↓

Typecheck

↓

Build

↓

Explain changes

↓

Stop
